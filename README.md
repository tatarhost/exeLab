# PulseForge Lite

A compact original Windows DAW-style music workstation.

## Features in this initial build

- Multitrack arrangement and editable pattern clips
- Piano roll with note grid, pitch labels, and note lengths
- Built-in sine, triangle, saw, and square synth voices
- Audio sample import
- Per-track volume, pan, and mute, plus master level
- Basic master delay effect
- MIDI import and export
- Project save/load (.pfsong)
- Offline 44.1 kHz stereo WAV rendering

## Windows build

Open **Actions → Build PulseForge Lite for Windows** and download the `PulseForge-Lite-Windows-x64` artifact after a successful run.

This is an original lightweight application, not an FL Studio clone or a redistribution of FL Studio components. VST hosting, recording, automation lanes, and advanced mastering are not included in this first version.
